# Proyecto 1 - API REST con Flask

Proyecto inicial desarrollado en Python y Flask.

## Archivos

- `application.py`: aplicación principal de Flask.
- `requirements.txt`: dependencias necesarias del proyecto.

## Ejecución local

1. Crear un entorno virtual.
2. Instalar dependencias con `pip install -r requirements.txt`.
3. Ejecutar la aplicación con `flask run` o `python -m flask --app application run`.
